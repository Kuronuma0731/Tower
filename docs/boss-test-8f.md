# 8F 守關怪 — 精算型 Boss 紙上測試

**目的**：用一隻具體的守關怪驗證 D1 的核心宣稱——「Boss = 一道必須精算才解得開的資源門」。要證明三件事：

1. 傷害預覽第一眼顯示**死亡**，但盤面上的資源存在多條活路（不精算就死，精算就活）
2. 不同活路的**代價結構不同**，且後果延伸到下一層（跨層取捨）
3. 全程確定性、無操作——戲劇張力只來自數字

**本文件同時是 `DamageFormula` 的驗收測試向量**：Core 第 1 步寫完公式後，下面每一格數字都必須被單元測試重現。

**數值狀態**：紙上暫定。公式形狀在 Core 動工時鎖定；具體數字由數值管線與驗證器迭代，本文件的數字只需自洽。

## 紙上版 DamageFormula（暫定）

```
我方單擊 = max(0, 我方攻 − 敵方防)
敵方單擊 = max(0, 敵方攻 − 我方防)

若 我方單擊 = 0 → 不可擊殺：預覽顯示「無法戰勝」，驗證器同判（不得除零）

所需回合 = ceil(敵方HP / 我方單擊)          // 我方出手次數
敵方出手次數 = 所需回合 − 1                  // 我方先手，最後一擊敵方無回應
```

特性修正（確定性，可疊加）：

| 特性 | 修正 |
|---|---|
| 先攻 | 敵方出手次數 +1（開戰前先出手**一次**——此次出手同樣套用連擊等出手修正，所以先攻+連擊的先制是 2 下） |
| 連擊 | 敵方每次出手打 2 下 |
| 魔攻 | 敵方單擊 = 敵方攻（無視我方防；此時敵方單擊永不歸零） |
| 吸血 | 敵方每次出手後，回復等同該次總傷害的 HP。所需回合改為：滿足 `n×我方單擊 − (n−1)×每輪回復 ≥ 敵方HP` 的最小 n；**我方單擊 ≤ 每輪回復 → 不可擊殺**，預覽顯示「無法戰勝」 |

**預期損血 = 敵方出手次數 × 每次出手下數 × 敵方單擊** ——傷害預覽顯示的就是這個數字（不可擊殺時不顯示數字，顯示「無法戰勝」）。

## 精算表

**方案 A｜直接打（預覽第一眼）**
我方單擊 30−24 = 6 → 需 ceil(300/6) = 50 回合。敵方出手 50 次（49+先攻1）× 2 下（連擊）× 單擊 (30−20)=10 → **預期損血 1000**。HP 520 → **預覽：死亡**。玩家被迫回頭看盤面。

**方案 B｜全攻**：120 經驗全換攻 → 攻 36
單擊 12 → 25 回合 → 損血 25×2×10 = **500** → 活，**剩 20 HP**（貼地通過）

**方案 C｜全防**：120 經驗全換防 → 防 26
單擊仍 6 → 50 回合 → 敵方單擊剩 4 → 損血 50×2×4 = **400** → 活，**剩 120 HP**（本層最優）

**方案 D｜均衡**：+3 攻 +3 防
單擊 9 → 34 回合 → 敵方單擊 7 → 損血 34×2×7 = **476** → 活，**剩 44 HP**

**方案 E｜換血路線**：120 經驗全換 HP（+300）→ HP 820 < 1000 → **仍然死亡**。HP 是本戰最差的兌換方向——但買一瓶血瓶（80 金幣，+150）疊加 B 或 D 即可放寬餘裕。

## 測試要驗證的四個設計論點

1. **連擊讓防禦價值翻倍**：本戰每 +1 防省下 2×出手次數 的血（C 方案 100 血/點）。7F 魔攻剛把堆防策略擊穿，8F 守關又把防禦拉回來——5F–8F 完成防禦價值的「漲—漲—跌—漲」雙擺，玩家的祭壇策略被迫全程動腦。
2. **本層最優 ≠ 全局最優**：C（全防）本戰剩血最多，但攻擊停在 30——9F 吸血怪的結算（見公式表吸血行）下，低攻方案的淨削減最小、成本最高，甚至落入「我方單擊 ≤ 回復」的不可擊殺區。8F 的選擇，後果在付費牆後兌現——這就是 cliffhanger 的機制版。
3. **沙漏對守關戰無意義**：預覽是精確的，不存在「試一下再後悔」——回溯道具的價值全在探索決策，不在戰鬥。這是 D7 與 D1 的自洽性證據。
4. **零傷閾值必須不可達**：檢查的正確形式是「按 `DamageFormula` **含特性**結算後，敵方單擊 = 0 的狀態在當層資源上界內不可達」——不是裸比較「玩家防 ≥ 怪攻」（那對魔攻怪是錯的：魔攻無視防禦，敵方單擊永不歸零）。本怪無魔攻，條件退化為玩家防 ≥ 30；紙上費率下最高只能到防 26，安全。
