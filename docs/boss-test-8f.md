# 8F 守關怪 — 精算型 Boss 紙上測試

**目的**：用一隻具體的守關怪驗證 D1 的核心宣稱——「Boss = 一道必須精算才解得開的資源門」。要證明三件事：

1. 傷害預覽第一眼顯示**死亡**，但盤面上的資源存在多條活路（不精算就死，精算就活）
2. 不同活路的**代價結構不同**，且後果延伸到下一層（跨層取捨）
3. 全程確定性、無操作——戲劇張力只來自數字

**本文件同時是 `DamageFormula` 的驗收測試向量**：Core 第 1 步寫完公式後，下面每一格數字都必須被單元測試重現。

**數值狀態**：紙上暫定。公式形狀在 Core 動工時鎖定；具體數字由數值管線與驗證器迭代，本文件的數字只需自洽。

## 紙上版 DamageFormula（暫定）

```
我方單擊 = max(0, 我方攻 − 敵方防)
敵方單擊 = max(0, 敵方攻 − 我方防)

若 我方單擊 = 0 → 不可擊殺：預覽顯示「無法戰勝」，驗證器同判（不得除零）

所需回合 = ceil(敵方HP / 我方單擊)          // 我方出手次數
敵方出手次數 = 所需回合 − 1                  // 我方先手，最後一擊敵方無回應
```

特性修正（確定性，可疊加）：

| 特性 | 修正 |
|---|---|
| 先攻 | 敵方出手次數 +1（開戰前先出手**一次**——此次出手同樣套用連擊等出手修正，所以先攻+連擊的先制是 2 下） |
| 連擊 | 敵方每次出手打 2 下 |
| 魔攻 | 敵方單擊 = 敵方攻（無視我方防；此時敵方單擊永不歸零） |
| 吸血 | 敵方每次出手後，回復等同該次總傷害的 HP。所需回合改為：滿足 `n×我方單擊 − (n−1)×每輪回復 ≥ 敵方HP` 的最小 n；**我方單擊 ≤ 每輪回復 → 不可擊殺**，預覽顯示「無法戰勝」 |

**預期損血 = 敵方出手次數 × 每次出手下數 × 敵方單擊** ——傷害預覽顯示的就是這個數字（不可擊殺時不顯示數字，顯示「無法戰勝」）。

## 盤面精算表（遞增價經濟，2026-08-08 重算）

**直接打（預覽第一眼）**：損血 **1000** vs HP 520 → **預覽：死亡**。玩家被迫回頭看盤面。

各種經驗分配（120 經驗上限）＋血瓶（80 金幣，+150 HP → 有效 HP 670）：

| 路線 | 經驗分配 | 攻/防 | 損血 | 無血瓶 | 有血瓶 |
|---|---|---|---|---|---|
| 全攻 | +4 攻（110） | 34/20 | 30回合×2×10 = **600** | 死 | **剩 70** |
| 全防 | +4 防（110） | 30/24 | 50回合×2×6 = **600** | 死 | **剩 70** |
| 偏防 | +1 攻 +3 防（95） | 31/23 | 43×2×7 = **602** | 死 | 剩 68 |
| 均衡 | +2 攻 +2 防（90） | 32/22 | 38×2×8 = **608** | 死 | 剩 62 |
| 偏攻 | +3 攻 +1 防（95） | 33/21 | 34×2×9 = **612** | 死 | 剩 58 |
| 換血 | 全換 HP／不換 | — | ≥1000 | 死 | 死 |

**三個重算後的發現**：

1. **血瓶是隱藏門票**：任何純經驗路線最低損血 600 > 520——不買血瓶必死。商店在守關戰首次成為守關資源的一部分（金幣從 QoL 變成生死線）。
2. **極端勝過均衡**：遞增價各屬性獨立計數，同樣 120 經驗，全攻/全防（各 4 點）買到的總點數比分散多——損血曲線呈倒 U，兩端最優（各剩 70）、中間最差。這是遞增價教給玩家的第一課。
3. **全攻與全防本戰打平，9F 分勝負**：吸血怪的淨削減規則讓低攻方案在 9F 成本暴增——8F 的平手是假的，付費牆後才揭曉。cliffhanger 的機制版仍然成立。

## 測試要驗證的四個設計論點

1. **連擊讓防禦價值翻倍**：本戰每 +1 防省下 2×出手次數 的血（全防路線 100 血/點）。7F 魔攻剛把堆防策略擊穿，8F 守關又把防禦拉回來——5F–8F 完成防禦價值的「漲—漲—跌—漲」雙擺，玩家的祭壇策略被迫全程動腦。
2. **本戰平手 ≠ 全局平手**：全攻與全防在本戰同剩 70，但全防路線攻擊停在 30——9F 吸血怪的結算（見公式表吸血行）下，低攻方案的淨削減最小、成本最高，甚至落入「我方單擊 ≤ 回復」的不可擊殺區。8F 的選擇，後果在付費牆後兌現——這就是 cliffhanger 的機制版。
3. **沙漏對守關戰無意義**：預覽是精確的，不存在「試一下再後悔」——回溯道具的價值全在探索決策，不在戰鬥。這是 D7 與 D1 的自洽性證據。
4. **零傷閾值必須不可達**：檢查的正確形式是「按 `DamageFormula` **含特性**結算後，敵方單擊 = 0 的狀態在當層資源上界內不可達」——不是裸比較「玩家防 ≥ 怪攻」（那對魔攻怪是錯的：魔攻無視防禦，敵方單擊永不歸零）。本怪無魔攻，條件退化為玩家防 ≥ 30；遞增價下 120 經驗最高只能到防 24（+10 防需 425 經驗），安全裕度比固定價時代更大。
